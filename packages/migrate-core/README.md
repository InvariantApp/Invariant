# @invariant-app/migrate-core

The part of a consumer migration that is the same in every language: the plan built from a release's Changes, byte-range edits that nest, and the sites a migration shows to a person instead of rewriting. Each language pack (`@invariant-app/migrate-ts`, `@invariant-app/migrate-py`) finds references, classes their roles and writes edits in these terms.

Part of [Invariant](https://github.com/InvariantApp/Invariant), which lets an API
provider change their API without breaking the integrations built against it.
Start with the [quickstart](https://github.com/InvariantApp/Invariant/blob/main/docs/quickstart.md).
