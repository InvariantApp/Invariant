# @invariant-app/symbols

Which SDK type implements each of a contract's schemas, and which SDK method calls each of its operations, read from a generated SDK release (TypeScript, Python or Go) and the OpenAPI document it speaks. Each entry says how it was found (the generator's own metadata, a naming convention, the fields the type declares, or a judge for what stayed tied) and how sure it is.

Part of [Invariant](https://github.com/InvariantApp/Invariant), which lets an API
provider change their API without breaking the integrations built against it.
Start with the [quickstart](https://github.com/InvariantApp/Invariant/blob/main/docs/quickstart.md).
