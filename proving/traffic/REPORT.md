# Traffic through the adapter

Rig C. For every corpus pair that closes, seeded requests shaped by the old
contract are sent to a mock of the old API, to a mock of the new API, and
to the new API through the proxy running the compiled program. Every
verdict comes from an independent JSON Schema validator, not from the code
under test. Generated by `pnpm proving:traffic`.

## Result

- 29 closing pairs, 4 could not be run
- **0 sites with violations through the adapter** (0 of 137144 samples)

### Sites the adapter serves

- 2 sites, 2 judged
- 2 where the unadapted API broke the old caller, and so prove something
- 0 vacuous: the old caller was not broken without the adapter
- 56 samples the rig could not judge: the old mock refused its own contract's request or response
- 28 samples whose generated response the new contract itself rejects

### Sites retired with guidance

- 1383 sites, a declared loss: 0 refused, which must answer 410 without reaching the API, and 1383 passed on, which must reach it and change nothing but a 405 or 410 into the guidance
- 0 did not
