A judge is now offered the fields inside an object a release added, by their
dotted path, beside the object itself. A value that moved into a new wrapper
on its own, as a request becoming a JSON:API `data` object does, used to be
answered as having no successor, because the wrapper alone plainly does not
hold it; it can now be answered with the field that does, which is the place
a `move` is drafted to. Jev's and S2's questions say so, and Jev's cache
fingerprint now covers all of its wording.
